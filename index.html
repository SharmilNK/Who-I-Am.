Nomad

Duke AI Hackathon 2025 : Winner Robotics Track

An AI voice-activated road trip companion built on a Raspberry Pi. A background thread continuously fetches images from the Pi's camera and uses GPT-4o Vision to detect location signs, landmarks, and points of interest, storing observations as vector embeddings in a persistent ChromaDB memory store. A foreground voice loop listens for the wake word "Nomad," transcribes the user's question, retrieves relevant memories via semantic search, and generates a conversational travel guide response with GPT-4o-mini. Responses are synthesized to audio via TTS and played back through the Pi

Tools : OpenAI GPT-4o, OpenAI GPT-4o-mini, OpenAI TTS, ChromaDB, sentence-transformers, SpeechRecognition + Google Speech API, YOLOv8 / ultralytics, EasyOCR, Raspberry Pi
